feat(built-in-ai): run Built-in AI on Claude Haiku 5.5 instead of GPT-6 Luna

New installs start every Built-in AI feature on Claude Haiku 5.5. When you update, every feature, selection toolbar action, language detection and Translation Hub card that runs on GPT-6 Luna or DeepSeek V4.1 Flash moves to Claude Haiku 5.5, including ones you picked yourself. Translation Hub cards that end up on the same model become one card. Features on GPT-6.2 Sol, Claude Sonnet 5.5 or your own providers stay where they are. A reasoning level you set for GPT-6 Luna or DeepSeek V4.1 Flash does not carry over: Claude Haiku 5.5 starts on its own default, and switching back to the old model brings back its level.
