# Third-party notices

## Word Hunter

The vocabulary hunter feature was inspired by and is compatible with data from
[Word Hunter](https://github.com/word-hunter/word-hunter), authored by `sapjax`
and its contributors.

Word Hunter's `package.json` declares the project license as MIT. The upstream
repository does not currently include a standalone license file, so this notice
records the source and declared license without making a broader claim about
third-party data contained in that repository.

The following file was imported from Word Hunter:

- `public/vocabulary/eng-dict.txt` (from Word Hunter's
  `public/eng-dict.txt`)

The implementation also provides compatibility with Word Hunter backup and
Chrome Sync data formats. The ReadFrog code implementing that compatibility was
written for this contribution.
