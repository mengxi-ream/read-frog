# Read Frog Subtitle Export

This context describes the language around exporting high-quality translated subtitles from Read Frog-assisted YouTube viewing workflows.

## Language

**AI-translated SRT**:
A subtitle file in SRT format whose subtitle text comes from Read Frog's AI subtitle translation into the user's configured target language, aligned to the source video's subtitle timing.
_Avoid_: source subtitles, bilingual subtitles, hard subtitles, finished video

**Source subtitles**:
The original caption track fetched from YouTube before AI translation.
_Avoid_: translated subtitles

**ASR source subtitles**:
Source subtitles generated by YouTube automatic speech recognition rather than uploaded by a human caption author. They may contain rolling fragments, repeated partial phrases, and weaker sentence boundaries.
_Avoid_: human subtitles, finished subtitles

**Human source subtitles**:
Source subtitles authored or uploaded by a human caption creator. When available, they are the preferred input for AI-translated SRT because they usually have better text quality and timing than ASR source subtitles.
_Avoid_: ASR subtitles, auto-generated subtitles

**AI segmentation**:
Read Frog's AI-assisted subtitle boundary refinement that turns source subtitle material into more readable subtitle lines before translation or export.
_Avoid_: raw YouTube segmentation

**Complete export**:
An AI-translated SRT where every exported subtitle line has a successful translation in the target language. A partial or silently degraded file is not a complete export.
_Avoid_: best-effort export, partial export

**Complete timed export**:
An AI-translated SRT whose translated lines are present and whose timing preserves the source subtitle coverage closely enough that spoken content is not silently compressed into an earlier cue or left as a playback gap. It may repair affected spans when AI segmentation produces timing holes.
_Avoid_: text-only complete export, timing-degraded export

**In-plugin export action**:
A Read Frog subtitle panel action that generates and downloads an AI-translated SRT using the extension's existing provider configuration and subtitle processing pipeline.
_Avoid_: external script, separate downloader

## Example Dialogue

Dev: Should the first export include both source and target language lines?

Domain Expert: No. The first export should be an AI-translated SRT in the target language only. Source subtitles are input material.

Dev: Are ASR source subtitles good enough to export directly?

Domain Expert: No. ASR source subtitles are input material; the export should use Read Frog's processed and AI-translated subtitle lines.

Dev: If a video has both human English subtitles and YouTube auto-generated English subtitles, which source should we use?

Domain Expert: Use human source subtitles first. ASR source subtitles are only a fallback when no suitable human source subtitles are available.

Dev: Should exported SRT use YouTube's raw subtitle boundaries?

Domain Expert: No. Exported SRT should preserve Read Frog's AI segmentation whenever it is enabled and available.

Dev: If source and target languages already match, should translated export download source-processed subtitles?

Domain Expert: No. Reject the translated export and direct the user to the existing source-subtitle download action.

Dev: If one subtitle line fails to translate, should we still download the file?

Domain Expert: No. A complete export requires every line to be translated; failed exports should stop and report the problem.

Dev: If AI segmentation keeps the translated text but creates a visible timing gap, is the export complete?

Domain Expert: No. A complete timed export must preserve subtitle timing coverage closely enough for playback. If AI segmentation creates a timing hole, the export should repair the affected span rather than silently downloading a timing-degraded file.

Dev: Should the first version be a separate command-line tool?

Domain Expert: No. The first version should be an in-plugin export action so it can reuse Read Frog's existing subtitle track selection, AI segmentation, provider configuration, and download flow.
