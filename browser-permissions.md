# Browser permissions

The extension declares its permissions in [`wxt.config.ts`](wxt.config.ts#L45).
WXT writes these values to each generated manifest.

The **Optional** column refers to manifest-level optional permissions.
The project does not declare `optional_permissions` or `optional_host_permissions`.
A feature can remain user-triggered while its permission remains required.

## Scope notes

- `*://*/*` covers HTTP and HTTPS pages on all hosts.
- Browser policy blocks injection into protected pages.
- Browser settings can separately control extension access to local files.
- `web_accessible_resources.matches` controls resource loading. It does not grant an extension API permission.
